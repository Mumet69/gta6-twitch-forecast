Forecasts GTA VI's launch-day Twitch concurrent viewers hour by hour (hours 2–24) as five quantiles. It anchors on the known hour-1 print and learns the launch-day shape from the 38 past launch curves shipped in each case: a weighted log-log regression per hour (rolling-midnight and console-only launches weighted most, since GTA VI unlocks at midnight local on consoles), blended with the pooled median launch-day shape, with a quantile spread calibrated so the 90% band covers about 90% of scored hours. Practice mean pinball loss 0.142 vs the house baseline's 0.387. Python 3.13, standard library only, fully offline and deterministic.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
